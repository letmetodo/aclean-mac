# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting channel for this repository:

**[Report a vulnerability privately](https://github.com/letmetodo/aclean-mac/security/advisories/new)**

Do not disclose vulnerability details in a public issue, discussion, or release comment. Include the affected AClean version, macOS version, affected feature, steps to reproduce, and impact. Remove personal paths, credentials, and unrelated user data from any evidence.

The maintainers will review reports through GitHub Security Advisories and coordinate a response there. This project does not promise a fixed response time.
